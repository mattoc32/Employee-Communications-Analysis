# Employee Communications Analysis

**November 16, 2026** · R · Data Analysis

## Project Overview

An analysis of employee communications performance on Viva Engage, with a focus on examining reach, engagement and link activity across 42 unique posts.

## Key Findings

- Announcements generated higher median reach rates.
- Standard posts generated higher median interaction rates.
- Link activity provides an opportunity to measure campaign outcomes more effectively.

## Tools Used

R, RStudio, readxl, dplyr, ggplot2, tidyr and R Markdown.

## Repository Contents

- **Data** – Source dataset used for the analysis
- **R Analysis Notebook** – Data cleaning, exploration, and analysis
- **Visualizations** – Charts illustrating communication performance
- **Statistical Analysis** – Statistical comparisons of post performance
- **Leadership Recommendations** – Business insights and recommendations
- **Presentation** – Summary of findings and business implications

## Business Recommendation

Adopt a **two-lane publishing strategy** that aligns communication format with the intended outcome:

- Use announcements while maximizing employee reach.
- Use standard posts when encouraging interaction and engagement.
- Evaluate link activity alongside campaign outcomes.
